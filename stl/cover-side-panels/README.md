# Side Cover Panels

This directory contains four 3D-printable side panels for the customized crawler based on the tracked robot platform originally designed by **Dejan Nedelkovski**.

These panels replace the bulky upper structures above the tracks in the original design. Those structures are not required for this crawler configuration, so the replacement panels help reduce overall weight while providing a simpler side enclosure.

The panels attach to the **existing mounting points of the original chassis using M3 screws**. **No modifications to the original chassis are required.**

## Included parts

| File | Location and purpose |
| --- | --- |
| `side-panel-front-left.stl` | Front-left side panel, incorporating a switch mounting position. |
| `side-panel-front-right.stl` | Front-right side panel, incorporating a switch mounting position. |
| `side-panel-rear-left.stl` | Rear-left side panel. |
| `side-panel-rear-right.stl` | Rear-right side panel. |

*Left and right are defined relative to the crawler's forward driving direction.*

## Switches and wiring

Both front side panels accommodate a switch. For the intended electrical connections, consult the **crawler-pi wiring schematic** before installation.

The wiring documentation is the authoritative reference for switch connections. Do not infer contact assignments or electrical functions from the STL geometry alone.

When installing the switches, provide enough wire clearance and strain relief to avoid interference with the tracks or the hinged top covers.

## Assembly

1. Identify the front/rear and left/right panels.
2. Position each panel against the corresponding original chassis mounting points.
3. Secure the panels with M3 screws.
4. Check clearance around the tracks, suspension movement, and any externally mounted sensor hardware before operating the crawler.

Do not overtighten screws against the 3D-printed parts. Confirm appropriate screw engagement and fit during assembly.

## Design attribution

These side panels are part of a custom adaptation of **Dejan Nedelkovski's original tracked robot platform**. The original chassis remains unchanged, and the replacement panels use its existing mounting interfaces.
